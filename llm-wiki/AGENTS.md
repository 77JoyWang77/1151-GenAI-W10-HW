# AGENTS.md — LLM Wiki 規則（v2，依需求訪談產生）

主題：**LLM Wiki 本身**（Karpathy 的 pattern、它的風險與改善方式）。
每條規則後面的〔Qn〕對應 `interview/summary.md` 的訪談題號，方便逐條對照。

## 1. 這個 wiki 給誰用
- 主要讀者是 **AI**：用來產生教學 HTML 簡報的知識庫，人偶爾看〔Q1〕〔Q7〕
- 所以格式要固定、好解析：固定的 frontmatter、固定的段落標題、一行一個事實〔Q1〕
- 不為簡報以外的用途（問答、其他專案）額外寫內容〔Q7〕

## 2. 資料夾
```
raw/      來源卡片（只讀，人挑選）
wiki/
  index.md      目錄：每頁一行 TLDR，AI 先讀這裡
  log.md        只追加的操作紀錄
  sources/      來源摘要頁
  concepts/     概念頁
  claims/       主張頁
  queries/      查詢結果（例如簡報大綱），由腳本產生
```

## 3. 頁面類型：只有三種〔Q2〕

| type | 一頁放什麼 | 檔名 |
|---|---|---|
| `source` | 一篇來源：在講什麼、重點、可信度 | `sources/sN-簡稱.md` |
| `concept` | 一個概念的定義與運作方式，綜整多個來源 | `concepts/概念.md` |
| `claim` | **一個**可以被驗證或反駁的主張，以及支持／反對的來源 | `claims/主張簡稱.md` |

- 不設比較頁；「A vs B」寫成主張頁，例如「LLM Wiki 會累積、RAG 不會」〔Q2〕
- `queries/` 是 query 的產出，不算 wiki 頁面類型，由腳本生成

## 4. 頁面格式
每頁（index、log 除外）的 frontmatter：
```yaml
---
title: 中文標題 (English Term)
type: source | concept | claim
sources: [S1, S2]
updated: YYYY-MM-DD
tldr: 一句話重點
---
```
- 中文撰寫，術語第一次出現附英文〔Q3〕
- **每一條 bullet 都要標來源 ID**，格式 `[S1]` 或 `[S1, S2]`〔Q4〕〔Q9〕
- 推論要寫成 `- （推論）...`，不標來源
- 頁面互連用 `[[檔名]]`；最後一節固定是 `## 相關頁面`

### 英文原句〔Q3〕
- 重要主張下一行可以附原句：`> "exact words" [S1]`
- 原句必須**逐字**出現在該來源 raw 卡片的 `## 原句` 段落
- 原句不超過 15 個英文字，不整段照抄

### 主張頁固定段落
```
## 主張        採信的說法（可信度最高的來源）
## 支持        其他支持的來源
## 註記        可信度較低、說法不同的來源（沒有矛盾就省略）
## 相關頁面
```

## 5. 來源可信度與矛盾處理〔Q5〕
raw 卡片 frontmatter 有 `rank`，數字越小越可信：

| rank | 類型 | 本 wiki 的來源 |
|---|---|---|
| 1 | 原始提案 | S1 |
| 2 | 實作教學 | S5 |
| 3 | 評論、比較 | S2、S3 |
| 4 | 產品文 | S4 |

- 來源說法互相矛盾時，**採信 rank 最小的一方**寫進 `## 主張`，其他放 `## 註記`，並寫出差在哪
- 只有產品文（rank 4）支持的說法，句首加「（廠商觀點）」

## 6. Ingest：批次〔Q6〕
1. 把所有新來源做成 raw 卡片：frontmatter（id、url、type、rank）＋ `## 重點`（改寫）＋ `## 原句`（短原句，逐字）
2. 全部讀完後，先列出：各篇 takeaways、彼此矛盾處、依第 5 節怎麼取捨、要新增／修改哪些頁 → 寫進 `log.md`
3. 一次寫入所有頁面
4. 統一跑 lint，失敗就修，**最多 3 輪**；3 輪後還有錯就停下，把剩下的錯誤交給人
5. lint 通過後 commit 一次

## 7. Lint（`python tools/lint_wiki.py`）〔Q8〕〔Q9〕
| 類別 | 檢查 |
|---|---|
| ① 格式與連結 | frontmatter 齊全、type 只能是三種之一、`[[連結]]` 不斷、沒有孤兒頁、index 列出所有頁 |
| ② 出處 | 每條 bullet 有來源 ID 或標（推論）；frontmatter `sources` 與內文一致；ID 存在於 raw |
| ③ 數字與原句 | bullet 裡的數字出現在引用來源的 raw 卡片；`>` 原句逐字出現在該來源的 `## 原句`，且不超過 15 字 |
| ④ 矛盾與可信度 | 主張頁 `## 主張` 引用的來源 rank 必須 ≤ `## 註記` 的來源；只引 S4 的 bullet 要有「（廠商觀點）」 |

- lint 抓不到「意思講反了」這種錯；這一類交給**另開新對話**的 AI 審查，只給它成品和來源

## 8. 禁止事項
- 不改寫 `raw/` 卡片既有的 `## 重點` 與 `## 原句`（可以補新欄位或新原句）
- 不用自己的知識補來源沒寫的內容；資料不足就在頁面寫「資料缺口」
- 不手寫 `queries/` 的頁面
