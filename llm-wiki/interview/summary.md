# 需求摘要（使用者已確認，2026-11-21）

| 面向 | 需求 | 依據 |
|---|---|---|
| 讀者 | 主要給 AI 讀：當之後做簡報的知識庫，人偶爾看 → 結構固定、好解析，比可讀性重要 | Q1 |
| 頁面類型 | 只有三種：來源摘要頁、概念頁、主張頁（一頁一個主張，標支持／反對來源）。不設比較頁 | Q2 |
| 語言 | 中文撰寫、術語保留英文；重要主張附英文原句（原句限短句，以免整段照抄來源） | Q3 |
| 出處 | 每句標來源 ID `[S1]`，不標段落 | Q4 |
| 矛盾 | 依來源可信度取捨：原始提案 > 實作教學 > 評論 > 產品文；採信一方寫進正文，另一方放「註記」 | Q5 |
| Ingest | 批次：全部來源讀完再一次寫入，最後統一 lint | Q6 |
| 產出 | 只為教學 HTML 簡報服務 | Q7 |
| Lint | ① 格式與連結 ② 每句有出處 ③ 數字與英文原句真的出現在來源 ④ 矛盾與可信度（產品文獨有主張要標出） | Q8、Q9 |
